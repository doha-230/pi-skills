# 출처와 적용 범위

- 원본: https://github.com/mattpocock/skills
- 버전: `1.2.3` (`package.json`)
- 가져온 커밋: `d81f3a183412e71a5b1e84ca21bc1a35eea03a60`
- 라이선스: MIT (`LICENSE`)

원본이 배포 대상으로 지정한 `skills/engineering/`과 `skills/productivity/`의 스킬 27개를 가져왔습니다. `misc/`, `in-progress/`, `deprecated/`는 원본의 배포 대상이 아니어서 제외했습니다. Pi의 스킬 디렉터리에 바로 풀 수 있도록 각 스킬 폴더를 `skills/<name>/`으로 모았습니다. 원본 파일 중 `Skill tool` 호출을 언급하는 스킬 9개에는 Pi에서 해당 스킬의 `SKILL.md`를 읽도록 안내하는 한 줄을 추가했습니다. 각 스킬의 나머지 내용과 보조 파일은 보존했습니다.
